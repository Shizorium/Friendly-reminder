# Friendly reminder

**Личные напоминания из чата для Foundry Virtual Tabletop.** Сохраняйте важные сообщения в отдельное окно, раскладывайте их по папкам и возвращайтесь к ним во время игры. Карточки сохраняют заголовок, изображения, оформление и полное содержимое.

Модуль для **Foundry VTT V13**: минимальная версия — **13.341**, проверенная — **13.351**. Обязательных зависимостей нет. Интерфейс доступен на русском и английском языках; оформление использует тему Foundry.

## Установка по ссылке

1. На стартовом экране Foundry откройте **Add-on Modules → Install Module** / **Модули → Установить модуль**.
2. Вставьте в поле **Manifest URL** ссылку:

   ```text
   https://github.com/Shizorium/Friendly-reminder/releases/latest/download/module.json
   ```

3. Нажмите **Install / Установить**.
4. Откройте мир, перейдите в **Настройки → Управление модулями** и включите **Friendly reminder**.

Эта ссылка всегда указывает на последний опубликованный релиз. Следующие версии можно устанавливать штатной кнопкой обновления модулей в Foundry.

Для ручной установки скачайте `friendly-reminder.zip` из [последнего релиза](https://github.com/Shizorium/Friendly-reminder/releases/latest), создайте папку `Data/modules/friendly-reminder` и распакуйте архив в неё. Файл `module.json` должен оказаться непосредственно в этой папке. Перезапустите Foundry, если модуль не появился в списке.

## Возможности

- **Кнопка над вводом чата.** Закладка находится в нижней строке над полем сообщения, в крайней правой позиции. При включённом Theatre она располагается справа от его кнопок сообщений.
- **Отдельное окно.** Начальная ширина соответствует чату. Окно можно перемещать, изменять его размер и сворачивать; масштаб карточек регулируется от 70 до 150%.
- **Сохранение карточек целиком.** Снимок включает заголовок, иконки, изображения и содержимое сообщения. Он остаётся в напоминаниях после удаления оригинала или очистки чата.
- **Свёрнутые записи по умолчанию.** Каждую запись можно раскрыть отдельно. Выбранное состояние сохраняется.
- **Папки.** Создавайте папки, сворачивайте их и переносите записи между ними и корнем перетаскиванием или через список назначения.
- **Удаление с подтверждением.** Крестик записи заменяется галочкой; удаление выполняется после повторного нажатия на том же месте.
- **Два способа удаления папки.** Удалите папку вместе с записями либо сохраните содержимое, переместив его в корень.
- **«Очистить всё».** Удалите все записи текущего пользователя, включая записи в папках. Сами папки сохраняются.
- **Повторная отправка в чат.** Отправляйте визуальную копию сохранённой карточки. Исходные броски и автоматизации повторно не запускаются; у личных сообщений сохраняются получатели.
- **Сохранение на сервере.** У каждой учётной записи свой список, папки и настройки окна. Они доступны после закрытия браузера, между игровыми сессиями и после смены домена того же сервера.

## Как пользоваться

Нажмите **закладку** над полем ввода, чтобы открыть окно. Сохранить видимое сообщение можно тремя способами:

1. Перетащить его из чата в окно, на нужную папку или на кнопку закладки.
2. Выбрать **«Сохранить в Friendly reminder»** в меню по правому клику на сообщении.
3. Нажать маленькую закладку в заголовке сообщения при наведении.

Потяните за заголовок окна, чтобы переместить его, или за правый нижний угол, чтобы изменить размер. Кнопка в заголовке и двойной щелчок по заголовку сворачивают окно; кнопка закладки также разворачивает его. Кнопки `−` и `+` меняют масштаб карточек, а нажатие на процент возвращает 100%.

### Записи

| Элемент | Действие |
| --- | --- |
| Стрелка или название | Развернуть / свернуть запись |
| Папка | Выбрать папку назначения или корень |
| Бумажный самолётик | Отправить копию в чат |
| Крестик → галочка | Подтвердить удаление записи |
| Перетаскивание за верхнюю строку | Переместить запись в папку или корень |

Ссылки на документы, раскрытие описаний и подробности бросков доступны в сохранённых карточках. Кнопки применения способностей из оригинальных карточек отключены: напоминание предназначено для просмотра и повторной отправки.

### Папки и очистка

Нажмите **«Новая папка»**, введите название и подтвердите галочкой или Enter. Перетаскивать сообщения можно и на заголовок свёрнутой папки.

- **Папка с минусом → галочка:** удалить папку, переместив все её записи в корень.
- **Корзина у папки → галочка:** удалить папку вместе с её записями.
- **«Очистить всё» → подтверждение:** удалить записи в корне и во всех папках, сохранив структуру папок.

Подтверждение любого удаления действует **5 секунд**. Его отменяют Escape, нажатие в другом месте или ожидание. Удаление напоминаний не удаляет исходные сообщения из чата.

## Где хранятся данные

Напоминания и папки записываются в **документ пользователя в базе мира Foundry**. Там же сохраняются положение и размер окна, масштаб, состояние окна и свёрнутость записей и папок. Модуль не использует хранилище браузера для этих данных.

После смены браузера или домена войдите **в тот же мир под той же учётной записью** — сохранённые записи будут доступны. При переносе на другой сервер перенесите базу мира и файлы изображений. Пути к изображениям с прежнего домена этого сервера преобразуются в относительные; внешние изображения продолжают зависеть от их источника.

Внешний вид карточек использует стили установленной игровой системы и модулей. Поэтому для прежнего оформления на другом сервере нужны те же стили. Модуль не привязан к конкретной системе; предусмотрена дополнительная обработка карточек D&D 5e и панели Theatre. Проверенная версия Foundry указана выше; совместимость с другими системами и изменяющими чат модулями может различаться.

## API для макросов

После загрузки мира:

```js
// Открыть окно напоминаний.
await game.modules.get("friendly-reminder").api.open();

// Сохранить видимое сообщение по его ID.
await game.modules.get("friendly-reminder").api.save("MESSAGE_ID");
```

## Разработка и сборка

Рабочие файлы модуля не требуют сборки или установки зависимостей. Для проверок нужен **Node.js 20+**:

```sh
npm test
```

В репозитории 19 проверок хранения, папок, перемещения, удаления, начального сворачивания и повторной отправки. Интерфейс дополнительно проверялся в изолированном окружении с `ApplicationV2` из Foundry 13.351.

Для подготовки архива релиза в PowerShell:

```powershell
./tools/package-release.ps1
```

В папке `dist` появятся `friendly-reminder.zip` и `module.json`. Архив содержит только файлы для установки; `module.json` находится в его корне. Перед новой версией обновите `version` в `module.json` и `package.json`, ссылку `download` в `module.json` и [историю изменений](CHANGELOG.md). Опубликуйте оба файла в GitHub Release с соответствующим тегом `v<version>`.
